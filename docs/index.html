RepoSync AI

Preview docs

RepoSync AI keeps your GitDigital Products organization aligned by synchronizing governance files, workflows, and documentation baselines from a central source of truth.

Introduction

Use RepoSync AI when you want to guarantee that every repository in your organization shares the same minimum governance, security documentation, and CI/CD structure.

Requirements

  • GitHub organization with admin access
  • GitHub App or PAT with permissions to read/write contents & workflows
  • A central configuration repository (for example, config-hub)

Installation

  1. Install the RepoSync AI GitHub App into your organization.
  2. Configure the list of target repositories and template paths in your config hub.
  3. Run an initial dry run to inspect the proposed changes.

Sync model

RepoSync AI uses a “central definition, local application” pattern: templates are defined once, then applied to each eligible repository with org‑specific rules and guards.

Safety & dry runs

Every sync operation can be executed in dry‑run mode, producing a report of pending changes before any commits are written. This is useful for audits and for gradual rollout across teams.
